# API онлайн-запису (сайт ↔ система MDS Connect)

Сайт (`site/`) записує клієнтів у ту саму систему, що й Telegram-бот (MDS Connect, папка `server/`).
Одне сховище — одна база записів, тому подвійних записів немає: зайнятий час зникає і на сайті, і в боті.

- **Базова адреса:** `booking.api_base` у `shared/config.json`, наприклад `https://m-d-production.up.railway.app`.
- **Режим:** `booking.api_mode` — `mock` (демо без сервера, `site/js/booking.js → mockApi`) або `live`.
- **Час:** локальний час салону, **Europe/Kyiv**, без зсуву (`YYYY-MM-DD`, `HH:MM`).
- **Формат:** JSON, UTF-8. Авторизація не потрібна (публічні маршрути `/api/public/*`).
- **Помилка:** `{"error": "<код>", "detail": "<повідомлення українською для клієнта>"}`.

## Увімкнення (live)

1. Railway → змінні сервісу: `MDS_PUBLIC_ORIGINS=https://<ваш-логін>.github.io` (адреса сайту; кілька — через кому).
   CORS дозволено лише цим доменам і лише для `/api/public/*`.
2. Панель MDS Connect → «Налаштування» → «Захист онлайн-запису» → ✓ «Онлайн-запис із сайту відкрито».
3. `shared/config.json`: `"api_mode": "live"`, `"api_base": "https://…railway.app"`.

Поки онлайн-запис не відкрито, усі маршрути (крім `/info`) відповідають `503`.

## GET /api/public/info

```json
{ "enabled": true, "salon_name": "M&D", "slot_step_min": 30, "date_from": "2026-11-04", "date_to": "2026-11-18", "now": "2026-11-04T14:10" }
```

## GET /api/public/services

Активні послуги з системи (ціни — у копійках).

```json
[{ "id": 12, "name": "Стрижка модельна", "section": "Чоловічі", "category": "Стрижки та послуги", "subcategory": null,
   "price": 45000, "price_from": false, "duration_min": 30 }]
```

Сайт зіставляє їх із `shared/services.json` за полем `system` (category + subcategory + name)
і бере ціну/тривалість із системи.

## GET /api/public/masters?service=ID

```json
[{ "id": 3, "name": "Маргарита" }]
```

## GET /api/public/slots?date=YYYY-MM-DD&service=ID[&master=ID]

Вільні часи початку. Без `master` (або `master=0`) — будь-який майстер.
Минулий час і час ближче за мінімальний відступ (налаштування `booking_min_lead_min`) **не повертаються**;
дата поза горизонтом запису — порожній список.

```json
{ "date": "2026-11-05", "slots": [{ "time": "09:00", "masters": [3, 5] }, { "time": "09:30", "masters": [5] }] }
```

## POST /api/public/bookings

```json
{
  "name": "Олена",
  "phone": "067 123 45 67",
  "service_id": 12,
  "master_id": null,
  "date": "2026-11-05",
  "time": "09:00",
  "comment": "",
  "website": "",
  "elapsed_ms": 18500
}
```

- `master_id`: `null` / `0` — будь-який вільний (сервер обере майстра).
- `website` — **пастка для ботів** (приховане поле; людина його не заповнює). Має бути порожнім.
- `elapsed_ms` — скільки часу заповнювали форму (мс). Менше 3000 — запит відхиляється.

**201 Created**

```json
{ "id": 1810, "status": "pending", "starts_at": "2026-11-05T09:00", "service": "Стрижка модельна", "master": "Дмитро",
  "message": "Дякуємо! Запис отримано — адміністратор підтвердить його найближчим часом." }
```

Записи з сайту завжди мають статус **pending** («очікує»): адміністратор телефонує клієнту й підтверджує.
У панелі запис позначено «з сайту»; директор отримує сповіщення в Telegram.

## POST /api/public/callbacks — «Швидка заявка»

Клієнт не обирає час: залишає ім'я, телефон і що хоче — адміністратор передзвонює. Заявка потрапляє в ті самі
«Просять передзвонити», що й «⚡ Швидкий запис» із бота (панель над календарем, бот директора, сповіщення).

```json
{ "name": "Олена", "phone": "067 123 45 67", "service": "Фарбування", "when": "Завтра", "comment": null,
  "website": "", "elapsed_ms": 9000 }
```

- `service` (≤ 60), `when` (≤ 40), `comment` (≤ 200) — необов'язкові; разом стають темою заявки
  (`Фарбування · Завтра`), без посилань.
- `website`, `elapsed_ms` — як у записі (пастка для ботів і мінімум 3 с заповнення).
- Повтор із того ж номера протягом години не створює нової заявки — повертається наявна.

**201 Created**

```json
{ "id": 7, "status": "new", "message": "Дякуємо! Заявку отримано — адміністратор зателефонує й підбере зручний час." }
```

## Коди відповідей і помилок

| Код | `error` | Коли | Що показує сайт |
|---|---|---|---|
| 201 | — | запис створено | підтвердження |
| 409 | `conflict` | час щойно зайняли | оновлює список часу, просить обрати інший |
| 422 | `validation` | невірне ім'я/телефон/час, посилання в тексті, пастка для ботів, надто швидке заповнення | текст помилки |
| 429 | `too_many` | ліміти (див. нижче) | текст + кнопки Telegram / дзвінок |
| 503 | `unavailable` | онлайн-запис вимкнено | текст + кнопки Telegram / дзвінок |
| 0 / 5xx | — | сервер недоступний | повідомлення + кнопки зв'язку; дані форми зберігаються |

## Захист від спаму

Спільні правила для бота й сайту (`server/mds/services/antispam.py`, налаштовуються в панелі):

| Правило | За замовчуванням |
|---|---|
| Активних майбутніх записів на одного клієнта (номер телефону) | 2 |
| Нових онлайн-записів від клієнта за добу (скасовані теж рахуються) | 3 |
| Непідтверджених онлайн-записів у черзі загалом | 20 |
| Записів із сайту за годину загалом | 15 |
| Заявок «передзвоніть» з одного номера за добу | 2 |
| Клієнт заблокований (картка клієнта → «Заблокувати онлайн-запис») | запис лише через адміністратора |
| 2+ неявки за 90 днів | запис тільки з підтвердженням, навіть якщо в боті ввімкнено автопідтвердження |

Додатково для сайту (`server/mds/api/routers/public.py`): 5 спроб запису й 120 переглядів слотів з однієї IP
за годину / 10 хв, пастка `website`, мінімальний час заповнення, лише український номер, без посилань у тексті.
