# Сайт-візитка M&D Beauty Salon з онлайн-записом

Одна сторінка: перший екран зі **«Швидкою заявкою»** (послуга + коли зручно + ім'я й телефон — адміністратор
передзвонить), прайс вкладками, «Як записатися» у 3 кроки, майстри, про нас, галерея й до/після, подарункові
сертифікати, онлайн-запис із вибором часу, FAQ, контакти (години роботи зі статусом «Відчинено/Зачинено» за
київським часом, карта). Дизайн — світлий і яскравий (малиновий, сонячний, м'ятний, фіолетовий; Unbounded + Manrope).
Чистий HTML/CSS/JS, без фреймворків, без cookie й трекерів. Мова — українська.

```
site/
  index.html         сторінка
  css/styles.css     стилі (mobile-first)
  js/main.js         розділи сторінки з shared/config.json і shared/services.json
  js/booking.js      онлайн-запис із вибором часу (mock або live API)
  js/quick.js        «Швидка заявка» — передзвоніть мені (mock або live API: POST /api/public/callbacks)
  img/logo.svg       монограма M&D (плейсхолдер — замініть своїм логотипом)
  img/og.png         картинка для соцмереж (Open Graph)
  docs/api.md        контракт API запису
  TODO.md            що заповнити власнику
shared/
  config.json        УСІ налаштування: назва, контакти, години, майстри, прапорці акцій, режим запису
  services.json      прайс за категоріями
```

## Запуск локально

Сторінка читає `../shared/*.json`, тому сервер запускається з **кореня репозиторію**:

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000/site/
```

(Просто відкрити `index.html` подвійним кліком не вийде — браузер не дозволить читати JSON з диска.)

## Режими запису

Той самий режим діє і для «Швидкої заявки»: у mock вона зберігається лише в браузері, у live — потрапляє
в «Просять передзвонити» (панель над календарем і бот директора).

- `"api_mode": "mock"` — демонстрація: вільний час генерується за годинами роботи з `config.json`
  (поки години не задано — пн–сб 09:00–19:00), запис зберігається лише в браузері відвідувача.
- `"api_mode": "live"` — запис у систему MDS Connect (спільна база з Telegram-ботом). Як увімкнути — `docs/api.md`.

## Де подивитися

Сайт уже відкривається на сервері системи: **https://m-d-production.up.railway.app/site/**
(той самий сервер, тож для live-запису там не потрібні CORS і `api_base` — достатньо `"api_mode": "live"`).

## Публікація на GitHub Pages

1. GitHub → Settings → Pages → Source: **GitHub Actions**.
   (Для приватного репозиторію Pages доступний на платних планах GitHub; інакше — публічний репозиторій
   лише для сайту або Cloudflare Pages / Netlify з тією самою папкою.)
2. Workflow `.github/workflows/site.yml` збирає `site/` + `shared/` і публікує. Вручну: Actions → «Site (GitHub Pages)»
   → Run workflow. Щоб публікувалось автоматично при зміні `site/` чи `shared/` у `main`, додайте змінну
   репозиторію `SITE_PAGES=true` (Settings → Secrets and variables → Actions → Variables).
3. Адреса: `https://<логін>.github.io/<репозиторій>/`. Її ж додайте в `seo.site_url` і в змінну Railway
   `MDS_PUBLIC_ORIGINS` (для live-запису).

## Що перевірено

- Телефон (390 px) і комп'ютер (1400 px): усі розділи, меню, акордеони, липка кнопка «Записатися».
- Mock-запис: кнопка «Записатися» біля послуги підставляє її у форму; на сьогодні минулий час прихований
  (о 14:10 перший слот — 15:00 з урахуванням мінімального відступу 30 хв); після запису — підтвердження.
- Live-запис проти локального сервера MDS Connect: слоти з API, запис зі статусом «очікує» і позначкою «з сайту»,
  зайнятий час зникає, ліміт «2 активні записи на номер» спрацьовує з поясненням, CORS лише для дозволеного домену.

## Обмеження ФОП 1 групи

На сайті лише послуги населенню: без продажу товарів, оренди місць і онлайн-оплати.
Оплата — у салоні готівкою або карткою.
