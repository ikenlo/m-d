# План розвитку

## Етап 1 — робоча система ✅ (версія 0.1)
Сервер + БД, акаунти, календар, закриття замовлень, розрахунок часток, зміни і виплати,
фінансова панель, журнали, бекапи, Telegram-бот, веб-панель (PWA) для Android/Windows.

## Етап 2 — нативні застосунки Android і Windows
Рекомендовано **Flutter**: один код для Android і Windows, працює з тим самим REST API
(`docs/API.md`), бізнес-логіка лишається на сервері.

- [ ] Каркас Flutter-проєкту `apps/mds_app` (тема M&D, авторизація, збереження токена в захищеному сховищі).
- [ ] Майстер: «Сьогодні», закриття замовлення, зміна, заробіток (порт екранів PWA).
- [ ] Push-сповіщення (FCM) про нові записи — як доповнення до Telegram.
- [ ] Офлайн-черга закриття замовлень (з тим самим `idempotency_key` — сервер уже готовий).
- [ ] Windows: повний кабінет директора/адміністратора, друк/експорт звітів.
- [ ] Збірка: APK/AAB, MSIX-інсталятор; CI-збірка в GitHub Actions.

До готовності нативних версій PWA повністю закриває потреби обох платформ.
