# Швидкодія — що зроблено і що свідомо не робимо

Чекліст оптимізації виконується по черзі; тут — стан кожного пункту.

## Зроблено (0.1.42)

| Пункт | Як |
|---|---|
| Стиснення | `GZipMiddleware` (від 1 КБ): `app.js` 334 КБ → ~89 КБ по мережі, JSON — у 3–5 разів менше. |
| Кеш статики | `index.html` підставляє `?v=<версія>-<хеш app.js+style.css>`; файли з `?v=` і шрифти — `Cache-Control: public, max-age=31536000, immutable`. Новий реліз = нова адреса, старий кеш не заважає. |
| Шрифти | Власні копії Manrope і Cormorant Garamond (`static/fonts/`, SIL OFL): лише кирилиця + латиниця, змінна вага, `font-display: swap`, preload основного. Жодних запитів до Google. |
| `defer` для app.js | HTML і стилі малюються, не чекаючи скрипта. |
| Скелети | Поки сторінка вантажить дані — сірі «заглушки» (`.view-skel`), зникають, щойно з'являється вміст. |
| Таймаути | `api.send`: GET — 20 с, зміни — 30 с; зрозуміле повідомлення замість «вічного» очікування. |
| Дедуплікація | Однакові GET, що летять одночасно, — один запит (`api.inflight`). |
| N+1 | «Журнал» 231 → ~10 SQL-запитів (пакетне завантаження імен), «Зміни» 214 → ~5 (виплати одним запитом), календар 80 → ~5 і «Замовлення» 40 → ~6 (`joinedload`/`selectinload`). |
| Індекси | Міграція 0023: `appointments(starts_at)`, `appointments(client_id)`, `orders(closed_at)`, `orders(master_id, closed_at)`, `orders(client_id)`, `orders(shift_id)`, `payouts(cash_shift_id)`, `expenses(spent_on)`, `audit_log(ts)`, `audit_log(entity, entity_id)`. Відкат — `alembic downgrade 0022`. |

Вже було раніше: debounce пошуку клієнтів (300 мс), сторінки по 40 у базі клієнтів, фонова черга
повідомлень (outbox / `sms_messages`), service worker для офлайн-оболонки.

## Не застосовується (і чому)

- **SSR/SSG, code splitting, віртуалізація, React-ре-рендери** — панель без фреймворку, один файл, DOM будується
  один раз на сторінку; списки — до кількох сотень рядків.
- **Redis, балансування навантаження** — один салон, один процес; SQLite/Postgres на тій самій машині Railway.
- **WebP/AVIF, lazy images** — у панелі немає фото, лише SVG-іконки.
- **Streaming відповідей** — немає довгих генерацій.
- **Brotli** — gzip достатньо; Brotli потребує додаткової залежності.
