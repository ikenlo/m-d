# Telegram-бот

Код: `server/mds/bot/` — `handlers.py` (клієнти), `staff.py` (персонал), `views.py` (тексти й кнопки),
`runner.py` (long polling + доставка черги). Тести — `tests/test_bot.py` (харнес `BotHarness` проганяє справжній
диспетчер aiogram). Правила канону — [CANON.md](CANON.md) §7 і рішення D-6b, D-7.

## Правила

- Бот — **тонкий адаптер**: кожна дія викликає сервіс з `Actor`; правил у боті немає.
- Усі повідомлення персоналу й клієнтам — через чергу `notifications` (outbox), доставка кожні 3 с
  (`runner.outbox_loop`), до 5 спроб.
- Дані користувачів у текстах — через `html.escape`.
- Клієнт бачить лише ім'я майстра (без прізвища). Повідомлення з кодом і PIN бот видаляє.
- **Білий список дій**, а не акаунтів: що можна робити, визначає роль користувача в системі.

## Клієнти (`handlers.py`)

Команди: `/start`, `/book`, `/free`, `/my`, `/services`, `/contacts`, `/staff`, `/link КОД`, `/today`.
- «📅 Записатися»: розділ → тип → вид → послуга → майстер (з найближчим вільним часом; один майстер — одразу дні) →
  день → час за частинами дня. Запис через `bookings.create_appointment` з `Actor.telegram` (роль `client`),
  тож діють антиспам (`services/antispam.py`), графік і захист від подвійних записів.
- «⚡ Швидкий запис» — клієнт лишає номер → заявка «передзвоніть» (`callback_requests`).
- «🕐 Вільний час», «💅 Послуги та ціни», «📍 Контакти» (з налаштувань), «Мої записи» (перенести, скасувати).
- Записи з бота мають статус `pending`, доки персонал не підтвердить (або ввімкнено автопідтвердження).
  Відповіді «Час зайнятий» / «Інший час» приходять клієнту кнопками.
- Нагадування за добу і за 2 години — за згодою клієнта (`services/reminders.py`).

## Персонал (`staff.py`)

**Вхід:** «👩‍🎨 Для майстрів» → спільний код персоналу (налаштування `bot_staff_code`, за замовчуванням `0000` —
змінити перед роботою) → вибір себе → особистий PIN (scrypt, задає директор). Сесія — 12 год.
Вхід підключає сповіщення для цього чату; альтернатива — `/link КОД` з «Профілю» панелі.

**Блокування (D-7):** 5 невдалих спроб коду або PIN → 15 хв. Зараз — лише в пам'яті процесу і для чату
(`StaffSessions.fail/locked`, тест `test_staff_pin_bruteforce_lock`). **[0.3.0]** зберігається в БД для **користувача**
і для чату, переживає перезапуск; кожна невдала спроба — в аудит.

### Дії сьогодні і в 0.3.0

Канон: бот лише **переглядає і підтверджує** (D-6b). Створення й редагування — на сайті.

| Дія (callback) | Хто | 0.3.0 |
|---|---|---|
| Мої записи / усі записи (`s:list`, `s:ld:`) | майстер — свої; директор — усі | ✅ перегляд |
| Підтвердити запис (`s:cf:`) | персонал | ✅ підтвердження |
| Заробіток (`s:earn`), фінанси (`s:fin`) | майстер — свій; директор — короткі звіти | ✅ перегляд |
| Підтвердити виплату (`s:pay`, `s:po:`) | директор | ✅ підтвердження |
| Заявки «передзвоніть» (`s:calls`, `s:cbd:`) | директор | ✅ (позначити оброблено) |
| **[0.3.0+]** Підтвердити / відхилити запит дозволу (режим відпустки) | директор | ✅ |
| **[0.3.0+]** Запит дозволу, його відкликання | майстер | ✅ |
| **Закрити замовлення** (`s:cl:`, `s:pm:`) | майстер, директор | ❌ **прибрати** (D-6b) |
| Додати запис (`s:add`…), перенести (`s:mv*`), скасувати (`s:del*`), «не прийшов» (`s:ns:`), «зайнято» (`s:busy:`), закрити зміну (`s:shift*`) | персонал | ❓ Q-12 у [CANON.md](CANON.md): за каноном — лише сайт; рішення директора перед пакетом 2.4 |

## Сповіщення

Директори отримують: нові записи, зміни, скасування, звіти змін, заявки, помилки бекапу.
Майстер — події своїх записів, виплати, виправлення заробітку. Повний перелік і рівні — [CANON.md](CANON.md) §5.

## Налаштування в @BotFather

`/setcommands`:
```
start - Головне меню
book - Записатися
free - Вільний час
my - Мої записи
services - Послуги та ціни
contacts - Контакти
staff - Для майстрів
```
Токен — лише змінна `MDS_TELEGRAM_TOKEN`. Бот працює в одному екземплярі (одна репліка сервера).
