# План розбиття `app.js` на модулі

**Дата:** 2026-11-13  
**Мета:** зменшити когнітивне навантаження на фронтенд, зберегти простоту ванільного JS.

## Поточний стан

- `server/mds/web/static/app.js` — **~5063 рядки** (~370 КБ)
- Ванільний JS, без збірки, без фреймворків
- DOM тільки через `h()`
- Один файл = уся логіка панелі

## Цілі

1. Зробити код читабельнішим і легшим для рев'ю.
2. Зберегти простоту (без важких залежностей і збірки на першому етапі).
3. Не змінювати поведінку UI.
4. Підготувати грунт для подальшого додавання вкладок без роздування файлу.

## Запропонована структура

```
server/mds/web/static/
  app.js                  ← точка входу (тонкий: імпорти + ініціалізація)
  core/
    h.js                  ← функція h() і хелпери DOM
    api.js                ← api.*, токен, обробка помилок
    store.js              ← localStorage / sessionStorage обгортки
    session.js            ← idle timeout, refresh токена
  views/
    calendar.js
    orders.js
    finance.js
    clients.js
    stock.js
    settings.js
    ...
  components/
    toast.js
    modal.js
    form.js
  app.js                  ← завантажує модулі та стартує
```

## Етапи

### Етап 1 — Підготовка (безпечний)
- Виділити `h()`, `store`, `session`, `api` в окремі файли.
- Залишити `app.js` як точку входу, яка імпортує їх (або просто підключає через `<script>`).
- Перевірити, що UI не зламався.

### Етап 2 — Виділення вкладок
- Кожну велику вкладку (Calendar, Orders, Finance, Clients, Stock, Settings) — в окремий файл.
- Залишити спільний стан (`state`) у `core/state.js`.
- Після кожного виділення — перевірка в UI.

### Етап 3 — Оптимізація (опційно)
- Легкий збірник (esbuild) тільки для конкатенації в production.
- Або залишити без збірки, якщо розмір дозволяє.

## Принципи

- Не змінювати `h()` і стиль роботи з DOM.
- Не вводити React/Vue/інші фреймворки.
- Кожен етап — окремий PR з перевіркою UI.
- Логувати в CHANGELOG.

## Наступний конкретний крок

1. Створити `core/h.js` і перенести туди `h()`.
2. Оновити `index.html` або `app.js`, щоб він підключав новий файл.
3. Перевірити, що панель відкривається.
