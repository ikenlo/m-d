# Запуск MDS Connect на Railway — покроково

Railway бере код прямо з GitHub (`ikenlo/m-d`, гілка `main`) і сам оновлює сервер після
кожного злиття Pull Request. Сервер — це одночасно програма (сайт / застосунок на телефоні),
Telegram-бот і автоматичні резервні копії. Одна база даних для всього.

Займає ≈ 15 хвилин. Робити краще з комп'ютера (з телефона теж можна, але незручно).

---

## Крок 0. Новий токен бота (обов'язково)

Старий токен був відкритий у переписці.

1. Telegram → **@BotFather** → `/mybots` → **@Mdstudioobot** → **API Token** → **Revoke current token**.
2. Скопіюйте новий токен (вигляд: `1234567890:AAH...`). Нікому не надсилайте — він знадобиться в кроці 4.

---

## Крок 1. Реєстрація

1. Відкрийте **railway.com** → **Login** → **Login with GitHub**.
2. Увійдіть акаунтом, якому належить репозиторій `ikenlo/m-d`, і дозвольте Railway доступ.
3. Новий акаунт отримує пробний період з одноразовим кредитом **5 $** — для старту картка не потрібна.

---

## Крок 2. Оплата (тариф Hobby)

Пробного кредиту вистачить на перші тижні, але щоб сервер працював постійно, потрібен тариф **Hobby**.

**Скільки коштує**

| Що | Ціна |
|---|---|
| Тариф **Hobby** | **5 $ на місяць**, з них 5 $ — це вже включене використання (процесор, пам'ять) |
| Диск для бази (Volume) | 0,15 $ за 1 ГБ на місяць — нам вистачить 1 ГБ (≈ 0,15 $) |
| **Разом для салону** | **≈ 5–6 $ на місяць** (≈ 210–250 грн). Більше лише якщо навантаження зросте |

**Як оплатити**

1. Угорі праворуч — ваш аватар → **Account Settings** (або **Workspace → Settings**) → **Plans / Billing**.
2. Оберіть **Hobby** → **Upgrade**.
3. Введіть дані картки (**Visa / Mastercard**). Оплата в доларах, раз на місяць автоматично.
4. **Українська картка** (Монобанк, ПриватБанк та ін.) підходить, якщо в застосунку банку
   увімкнено **платежі в інтернеті** та **оплату в іноземній валюті**. Зручно взяти окрему віртуальну картку
   і поповнювати її на ≈ 300 грн на місяць — так ви контролюєте витрати.
5. **Обмеження витрат** (рекомендую): **Billing → Usage Limits** → задайте ліміт, напр. **10 $**.
   Railway попередить, якщо витрати наближаться до ліміту, і не спише більше.

Рахунки (інвойси) з'являються в тому ж розділі **Billing** — їх можна завантажити для обліку витрат.
Додайте їх у програмі в розділ **Витрати → Інше**.

> Точні назви пунктів меню Railway іноді змінює. Якщо щось називається інакше — шукайте **Billing** або **Plans**.

---

## Крок 3. Створення сервісу з GitHub

1. **New Project** → **Deploy from GitHub repo** → оберіть **ikenlo/m-d**.
2. Railway знайде файли `Dockerfile` і `railway.json` і почне збирати. **Перший запуск може завершитись
   помилкою — це нормально**, бо ще немає змінних і диска. Продовжуйте.
3. Відкрийте сервіс → **Settings** → **Source**: гілка **main** (за замовчуванням).
   Перевірте, що **Replicas = 1** (бот має працювати в одному екземплярі).

---

## Крок 4. Диск і змінні

**Диск (обов'язково, інакше база зникне після оновлення):**
сервіс → правий клік / **⋯** → **Attach Volume** (або **Settings → Volumes → New Volume**) →
Mount path: **`/data`** → розмір 1 ГБ.

**Змінні:** сервіс → **Variables** → **New Variable**:

| Назва | Значення |
|---|---|
| `MDS_TELEGRAM_TOKEN` | новий токен бота з кроку 0 |
| `MDS_DIRECTOR_USERNAME` | логін директора, напр. `margaryta` |
| `MDS_DIRECTOR_PASSWORD` | пароль директора (8+ символів, літери й цифри) |
| `MDS_DIRECTOR_NAME` | `Маргарита` |

Збережіть — Railway перезапустить сервіс. При першому запуску система сама:
застосує структуру бази, створить директора і завантажить прайс салону (42 послуги).

Після успішного входу **видаліть змінну `MDS_DIRECTOR_PASSWORD`** (пароль уже збережено в базі в зашифрованому вигляді).

---

## Крок 5. Адреса сайту

Сервіс → **Settings** → **Networking** → **Generate Domain**. З'явиться адреса на кшталт
`md-salon.up.railway.app` (з HTTPS).

- Відкрийте її → увійдіть як директор.
- **Android:** Chrome → ⋮ → **Додати на головний екран / Встановити застосунок**.
- **Windows:** Edge/Chrome → значок **Встановити** в адресному рядку.
- Свій домен (напр. `crm.md-salon.com.ua`): **Networking → Custom Domain** — Railway підкаже, який запис додати в DNS.

---

## Крок 6. Налаштування після запуску

У програмі як директор:

1. **Налаштування → Telegram-бот** — змініть код персоналу `0000` на свій; перевірте адресу й телефон.
2. **Персонал → + Співробітник** — додайте майстрів: логін, пароль, **PIN для бота**, відсоток, послуги, графік.
3. **Налаштування → Графік салону** — перевірте години роботи.
4. У Telegram кожен (і директор) входить у бот: **«👩‍🎨 Для майстрів» → код → себе → PIN** — після цього
   сповіщення приходять кожному особисто.

---

## Як оновлюється система далі

1. Claude (або розробник) робить зміни в окремій гілці й відкриває **Pull Request** на GitHub.
2. Автоматичні тести (**CI**) перевіряють зміни — має бути зелена галочка ✅.
3. Ви переглядаєте опис і натискаєте **Merge** (можна із застосунку GitHub на телефоні).
4. Railway сам збирає нову версію й перезапускає сервер (≈ 1–3 хв; бот у цей час недоступний).
   Нові поля в базі додаються автоматично (міграції), дані зберігаються.

Нічого не потрапляє на сервер без вашого «Merge».

---

## Резервні копії

- Автоматично щодня на тому ж диску (`/data/backups`, останні 30) + кнопка **Налаштування → Створити копію зараз**.
- Railway також дозволяє робити знімки диска: сервіс → Volume → **Backups** (якщо доступно на тарифі).
- Раз на місяць варто завантажувати копію собі (попросіть Claude додати кнопку «Завантажити копію», якщо потрібно).

## Якщо щось не працює

- Сервіс → **Deployments** → останній → **View Logs**. Повідомлення системи — українською.
- «Директора ще немає» — не задано `MDS_DIRECTOR_USERNAME` / `MDS_DIRECTOR_PASSWORD`.
- Бот мовчить — перевірте `MDS_TELEGRAM_TOKEN`; у логах має бути `Telegram-бот @Mdstudioobot запущено`.
- Пишіть Claude текст помилки з логів — він знайде причину.
