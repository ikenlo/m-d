# Оплата карткою — «Термінал» ПриватБанку на планшеті (NFC)

Планшет на Android з NFC і застосунком «Термінал» ПриватБанку (`ua.privatbank.pterminal`) працює як платіжний
термінал. Документація банку: https://app.privatbank.ua/nfcpos, інструкція: privatbank.ua/handbook/sumishennya_zastosunok_terminal.

## Як працює
1. Закриття замовлення → спосіб оплати **«Термінал (NFC)»** → «Оплатити на терміналі».
2. Сервер створює оплату (`card_payments`, статус `pending`) і отримує в банку токен операції (`token.php`, підпис
   `sha1(signed + secret + data + secret)`), повертає deeplink `nfcterminal://executor?token=…&callback=…`.
3. Застосунок MDS (Android) відкриває «Термінал» з сумою; клієнт прикладає картку/телефон.
4. Після повернення в MDS **сервер сам перевіряє результат у банку** (`check.php`). Лише `response_code = "00"` →
   оплата `paid` і замовлення закривається як «Картка» (ключ ідемпотентності `card-<id>`) в одній транзакції.
   Зберігаються RRN, код авторизації, маска картки, платіжна система, HTML-чек банку.
5. Відмова → `failed`, запис лишається відкритим, можна повторити або взяти готівку.

Захист: подвійне натискання повертає ту саму операцію; повторна перевірка не задвоює замовлення; «Скасувати»
спершу питає банк (якщо клієнт уже заплатив — оплата зараховується, а не губиться); банк недоступний — помилка
з пропозицією перевірити пізніше, нічого не втрачається (незавершену оплату можна перевірити будь-коли).

## Режими (`card_terminal_mode`, «Налаштування»)
- `off` — вимкнено (за замовчуванням); `mock` — імітація без списання грошей (кнопки «Імітувати оплату/відмову»);
- `live` — реальні оплати; потрібні змінні сервера `MDS_PRIVAT_TERMINAL_CLID`, `MDS_PRIVAT_TERMINAL_SECRET`
  (видає банк інтегратору) і `MDS_PRIVAT_TERMINAL_CLIENT_TOKEN` (ключ підприємства з terminal.pb.ua → «Інтеграція»).

## Підключення
1. Еквайринг ПриватБанку → «Термінал» у смартфоні; встановити застосунок на планшет (Android, NFC).
2. Кабінет https://terminal.pb.ua/ — магазин і касир; меню «Інтеграція» → згенерувати ключ (client_token).
3. Ключі інтегратора (clid, secret) — запит до банку: maksym.soloninko@privatbank.ua; підтримка: terminal_app_support@privatbank.ua.
4. Ключі — лише у змінних Railway. Потім «Налаштування» → режим «Реальні оплати», пробна оплата 1 грн.

## Ще не зроблено
Повернення (`refund`) і реверс (`reverse.php`) з MDS — поки через застосунок «Термінал»; виправлення замовлення — директором.
