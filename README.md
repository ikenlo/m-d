# MDS Connect — внутрішня система салону M&D

Приватна система управління beauty-салоном **M&D**: записи клієнтів, робота майстрів,
закриття замовлень, автоматичний розрахунок зарплат (50/50 або індивідуально),
звіти змін, фінансова панель директора і Telegram-бот для запису клієнтів.

> Система створена **лише для одного салону**. Це не SaaS і не продукт для продажу.

## Швидкий старт

```bash
cd server
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m mds init                                     # створить БД і акаунт директора
MDS_TELEGRAM_TOKEN=123:ABC python -m mds run           # API + панель + бот + бекапи
```

Відкрийте `http://localhost:8000` і увійдіть як директор. Далі: **Послуги** → додайте послуги,
**Персонал** → створіть майстрів, **Профіль** → підключіть Telegram для сповіщень.

Детально: [docs/OPERATIONS.md](docs/OPERATIONS.md).
