# M&D Beauty Salon — сайт салону краси

Односторінковий адаптивний сайт у темно-зелених і золотих кольорах. Без фреймворків і збірки: HTML, CSS і чистий JavaScript.

## Що є на сайті

- **Головний екран**: слоган, кнопки запису, ключові цифри.
- **Про салон**: переваги та фото інтер'єру.
- **Каталог послуг і ціни**: 6 категорій (волосся, нігті, брови та вії, макіяж, догляд за обличчям, SPA). Біля кожної послуги вказані тривалість і ціна, а кнопка «Записатися» підставляє послугу у форму.
- **Галерея робіт**: фільтри за категоріями та лайтбокс (перегортання стрілками на клавіатурі та свайпом).
- **Майстри**: картки з кнопкою запису до конкретного майстра.
- **Відгуки**.
- **Онлайн-запис**: вибір категорії, послуги, майстра, дати (30 днів наперед) і вільного часу. Час, що вже минув, і зайняті слоти недоступні. Є маска телефону, перевірка полів і вікно підтвердження.
- **Контакти**: адреса, графік, соцмережі, карта Google.
- **Адаптація під смартфони**: бургер-меню, категорії гортаються вбік, плаваюча кнопка «Записатися».

## Як запустити

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Сайт можна розмістити на GitHub Pages, Netlify, Vercel або будь-якому хостингу статичних сайтів.

## Як редагувати

Увесь контент лежить у **`js/data.js`**:

| Що змінити | Де |
|---|---|
| Послуги, ціни, тривалість | `categories[].services` (`from: true` додає до ціни «від») |
| Майстри | `masters` (`categories` визначає, до яких послуг можна записатися до майстра) |
| Фото в галереї | `gallery` (`tall: true` робить фото високим) |
| Телефон, адреса, соцмережі, карта | `contacts` |
| Графік для запису | `booking.openHour / closeHour / weekendOpen / weekendClose` |

Кольори задаються змінними на початку `css/style.css` (`--green-*`, `--gold*`).

### Отримання заявок

Поки що заявки зберігаються тільки в браузері клієнта (`localStorage`). Щоб вони надходили в салон, вкажіть у `js/data.js` адресу обробника:

```js
booking: { endpoint: "https://your-server/booking", ... }
```

Форма надсилає `POST` із JSON такої структури: `service, category, master, date, time, name, phone, comment, price`. Обробником може бути Google Apps Script (запис у Google Таблицю), Formspree, Make/Zapier або власний бекенд із пересиланням у Telegram.
